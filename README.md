# Java Foundations and Version Control

A beginner-friendly Java project demonstrating core Object-Oriented Programming (OOP) concepts, a SOLID-based calculator application, and Git/GitHub version control workflows.

## Project Overview

This project was developed as part of the **Java Foundations and Version Control Internship Assignment**.

It focuses on strengthening Java programming fundamentals, understanding OOP principles, writing clean and maintainable code, and learning collaborative development practices using Git and GitHub.

## Objectives

- Understand Java classes, objects, and constructors.
- Implement encapsulation, inheritance, polymorphism, and abstraction.
- Develop a calculator application using SOLID principles.
- Learn Git commands and GitHub repository management.
- Practice feature-based branching and Pull Request workflows.

## Technologies Used

- **Programming Language:** Java
- **Version Control:** Git
- **Code Hosting:** GitHub
- **IDE:** Visual Studio Code
- **JDK:** Java Development Kit
